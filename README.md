# Zikoner Home Assistant Add-ons

## Add-ons disponibles

### 🔊 Alexa Manager

Gérez vos phrases vocales Alexa directement depuis Home Assistant.

**Fonctionnalités :**
- 📋 Voir toutes vos entités avec la phrase exacte à prononcer à Alexa
- ✏️ Renommer les appareils directement (Alexa détecte le changement automatiquement)
- ▶️ Tester les appareils directement depuis l'interface
- 🔍 Rechercher et filtrer par type ou état
- 📺 Gestion : Lumières, Prises, Scènes, Scripts, Climat, Volets, Médias

## Installation

1. Dans Home Assistant, va dans **Paramètres → Add-ons → Boutique des add-ons**
2. Clique sur **⋮** (3 points en haut à droite) → **Dépôts**
3. Ajoute : `https://github.com/zikoner/ha-addons`
4. Ferme, rafraîchis la page, cherche **Alexa Manager** et installe
5. Démarre l'add-on — il apparaît automatiquement dans la barre latérale

> ⚠️ Cet add-on n'est **pas** disponible via HACS. Il s'installe directement depuis la boutique des add-ons HA.
