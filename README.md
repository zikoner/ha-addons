# Zikoner Home Assistant Add-ons

[![Add repository to HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=zikoner&repository=ha-addons&category=integration)

## Add-ons disponibles

### 🔊 Alexa Manager

Gérez vos phrases vocales Alexa directement depuis Home Assistant.

**Fonctionnalités :**
- 📋 Voir toutes vos entités avec la phrase exacte à prononcer
- ✏️ Renommer les appareils (Alexa les détecte automatiquement)
- ▶️ Tester les appareils directement depuis l'interface
- 🔍 Rechercher et filtrer par type ou état
- 📺 Gestion : Lumières, Prises, Scènes, Scripts, Climat, Volets, Médias

## Installation via HACS

1. Ouvre HACS dans Home Assistant
2. Clique sur **"..."** → **Dépôts personnalisés**
3. Ajoute : `https://github.com/zikoner/ha-addons`
4. Catégorie : **Add-on**
5. Cherche **Alexa Manager** et installe

## Installation manuelle

1. Copie le dossier `alexa_manager` dans `/addons/` sur ton HA
2. Va dans **Paramètres → Add-ons → Boutique**
3. Clique ⋮ → **Vérifier les mises à jour**
4. Installe **Alexa Manager**
